# calculadora-consumo-combustivel

⛽ Calculadora de Consumo de Combustível

Aplicação web desenvolvida com HTML, CSS e JavaScript para calcular o consumo de combustível e estimar o custo de uma viagem com base nas informações fornecidas pelo usuário.

🎯 Objetivo

Praticar conceitos fundamentais de desenvolvimento front-end, incluindo estruturação semântica com HTML, estilização com CSS, funções JavaScript, validação de dados e manipulação do DOM.

🚀 Funcionalidades

- Informar a distância percorrida em quilômetros (km).
- Informar o consumo médio do veículo em quilômetros por litro (km/L).
- Informar o preço do combustível por litro (R$/L).
- Calcular a quantidade estimada de combustível consumido.
- Calcular o custo total estimado da viagem.
- Calcular o custo médio por quilômetro.
- Validar os valores informados antes de calcular.
- Exibir os resultados na própria página, com duas casas decimais.
- Limpar os campos após um cálculo válido.

🛠️ Tecnologias utilizadas

- HTML5: estrutura e campos do formulário.
- CSS3: apresentação visual e layout responsivo.
- JavaScript: cálculos, validações e atualização dos resultados no DOM.

▶️ Como executar

1. Clone o repositório:
   git clone URL_DO_SEU_REPOSITORIO
2. Abra a pasta do projeto no VS Code ou em outro editor.
3. Abra o arquivo index.html no navegador.
4. Preencha os três campos e clique em Calcular consumo.
Substitua URL_DO_SEU_REPOSITORIO pelo endereço real do projeto no GitHub.
